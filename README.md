# CopilotMail

[简体中文](README.zh-CN.md) · [English](README.en.md)

CopilotMail is an enterprise mail system under active development, designed
for humans and Agents as equal first-class principals.

CopilotMail 是一套正在开发中的企业邮件系统，以人与 Agent 均为第一公民作为
核心设计原则。
