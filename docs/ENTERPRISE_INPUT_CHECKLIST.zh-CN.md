# CopilotMail P0 公司输入与签字清单

> 状态：等待公司输入
> 用途：把实施计划第 15 节的未知条件转为具名决策、证据和放行门禁
> 注意：本文不得填写密码、Token、私钥、完整证书或生产 Secret

## 1. 使用方法

每项决策必须填写：

- **决定值**：可量化的数值、明确选项或适用法规；
- **负责人**：对输入正确性负责的公司角色或个人；
- **证据**：容量报表、供应商文档、合同、DNS 截图、演练记录或批准单；
- **复核日期**：输入何时需要重新确认；
- **状态**：`未确认`、`验证中`、`已批准` 或 `不适用`。

“尚不清楚”不能转换成无限容量或宽松安全默认值。未确认项使用保守上界并保持对应
生产能力关闭。详细风险和控制见[企业威胁模型](THREAT_MODEL.zh-CN.md)。
